# Selene 音乐播放器

一个可通过 Git 仓库链接直接安装的 SillyTavern 第三方音乐播放器扩展。

## 功能

- 在播放器设置中切换 GD 音乐、其他音乐或 B站网页
- MP3 等音频直链导入，并可给已有歌曲补充或更换音源
- 歌词显示与桌面悬浮歌词
- 播放队列、歌曲收藏与支持多选批量管理的自建歌单
- 喜欢、歌单、队列、陪听采用简洁导航，其余操作集中在“更多功能”
- 歌曲下载缓存与离线播放（优先使用浏览器实际播放源，失效地址会自动刷新签发，并在网易云和 JOOX 间回退）
- 导入网易云、QQ 音乐或酷狗歌单（三个平台的分享短链均可自动解析）
- 读取世界书中的作者推荐歌单
- 自动读取 AI 回复中的歌曲推荐
- iMessage 风格角色陪听（短尾气泡、自定义聊天背景、联系人私聊、固定群聊、`@` 定向发言、独立记忆与本地头像上传）
- 可切换 SillyTavern 当前模型或自定义 OpenAI 兼容 API，并获取模型列表
- 多种皮肤（默认专辑玻璃，含中国红、圆形流光唱片）、迷你模式与沉浸模式
- **设置 → 播放器窗口** 可选择圆形、方形或 Q 版 Selene，可独立开启吸附，选择屏幕边缘或聊天输入框上方；Selene 会眨眼、轻轻摆动，停在输入框上方时换成坐姿。点击“缩成悬浮窗”后可以拖动它，单击播放或暂停、双击恢复播放器；迷你位置单独保存。
- 播放器和歌词尺寸自定义
- 系统媒体保活
- 桌面端与移动端适配

## 安装

1. 打开 SillyTavern，点击顶部的「扩展」。
2. 选择「安装扩展」。
3. 粘贴本仓库的 HTTPS 链接：

   ```text
   https://github.com/soso454u/-
   ```

4. 点击安装，安装完成后会立即加载并显示播放器，不需要手动刷新。若不成功按照 SillyTavern 的提示重新加载页面。

> 请使用「安装扩展」，不是「下载扩展与资源」；第三方仓库不会出现在官方资源列表里。也请不要粘贴 `raw.githubusercontent.com` 文件链接、ZIP 下载链接或单个 JS 文件链接；SillyTavern 需要的是完整 Git 仓库链接。

### 酒馆助手脚本版

脚本版在 **酒馆助手 → 脚本** 里管理，不会以独立扩展的形式出现在 SillyTavern 的「管理扩展」列表中。

1. 已安装酒馆助手的用户，打开其中的「脚本」页，新建或编辑 Selene 播放器脚本。
2. 把仓库中 [`纯音乐播放器.js`](./纯音乐播放器.js) 的完整 JavaScript 内容粘贴进脚本编辑器，保存并启用。不要把 `index.js` 当作酒馆助手脚本，它是扩展版的加载入口。
3. 每次启用脚本会显示播放器；点击左上角 **×** 收起窗口，再从魔法棒菜单里的 **音乐播放器** 打开。关闭酒馆助手中的脚本开关会移除播放器及菜单入口。
4. 更新手动粘贴的脚本时，需要用最新文件内容替换旧代码；只更新扩展版或酒馆助手本身，不会替换原先粘贴的播放器代码。
5. 如果播放器窗口找不到，在酒馆助手里编辑 Selene 脚本，到「按钮」启用默认隐藏的 **强制打开播放器**。保存后点击该按钮，窗口会恢复到默认位置和大小，并重新补上魔法棒入口。

扩展版与脚本版建议选择一种启用，避免重复加载同一个播放器。

### LX Music 备用音源

**LX Music 第三方备用音源**默认开启。导入的 QQ 歌曲优先使用保存的播放地址，失效时可凭 QQ 歌曲 ID 通过 **LX Music · QQ** 取回同一条录音。其他歌曲通常先尝试 **GD 网易云**，再尝试 LX 和 JOOX。也可以用播放键左侧的双箭头为当前歌曲手选 LX，或在播放器设置关闭此功能。

Selene 直接通过内置的 Cloudflare Worker 获取 [Huibq LX Music 音源](https://github.com/Huibq/keep-alive) 的播放地址，安装后无需配置域名、启用代理或安装服务端插件。需要跨平台匹配时，Selene 按歌名、歌手、版本及可用时长从 Meting 搜索真实平台 ID。取址先试 128k，只有上游明确无地址或地址已过期时才试 320k。临时地址仅用于在线播放。

### 安装或关闭异常排查

- **`Directory already exists at data/default-user/extensions/-`，同时找不到 Selene**：这是本播放器的安装目录冲突。仓库名为 `-`，所以安装目录也叫 `-`，并非路径少写了名字；该报错只说明目录存在，不代表安装完整或播放器已加载。先按下方「目录已存在但扩展不可见」排查，重复点击安装不会更新或修复旧目录。
- **`Directory already exists ... /JS-Slash-Runner`**：服务器里已经存在酒馆助手目录。这个报错指向酒馆助手，不能据此判断 Selene 是否安装。页面已经显示「酒馆助手」时，应在其「脚本」页查看播放器脚本；安装独立扩展则使用本仓库 `https://github.com/soso454u/-`。
- **`Cannot get assets list / Problem with assets URL`**：这是「下载扩展与资源」中的资源列表读取失败。安装本仓库使用扩展面板的 **安装扩展** 按钮，完整 Git 仓库链接不应填进「资源 URL」。
- **安装后没有窗口**：扩展版在「管理扩展」确认 **Selene 音乐播放器** 已启用，再到扩展面板打开其「显示播放器窗口」；脚本版到酒馆助手的「脚本」页确认代码已保存并启用。也可从魔法棒菜单的 **音乐播放器** 打开。
- **旧脚本关不掉或开关关闭后窗口仍在**：替换成最新 `纯音乐播放器.js`，刷新一次后重新启用。新版关闭操作不依赖存储写入成功，隐藏状态也会防止主题样式覆盖；脚本 iframe 卸载会清理父页面的播放器，不受脚本改名影响。
- **菜单图标和名称上下换行**：新版入口会保持单行，继承菜单文字颜色，并为布局添加独立样式，兼容会改写扩展菜单布局的主题。

#### 目录已存在但扩展不可见

1. 重新加载酒馆页面，再打开顶部的 **管理扩展程序**，搜索 **Selene 音乐播放器**。扩展设置里的折叠面板由播放器代码创建；只有折叠面板不见时，也可能是扩展被禁用或代码加载失败。扩展管理列表则需要先成功读取 `manifest.json`。
2. 在同一个已登录的酒馆站点打开 `/scripts/extensions/third-party/-/manifest.json`（保留自己的域名和部署前缀，将地址末尾改为这段路径）。正常应显示 JSON，其中 `display_name` 是 `Selene 音乐播放器`。404、登录页、拒绝访问或无效内容，说明清单没有正常送达，需要进一步检查安装文件、当前账号与服务器路由；不能仅凭 404 就断定文件已丢失。JSON 正常但面板仍不见时，再检查同目录的 `index.js`、`纯音乐播放器.js` 和浏览器控制台的加载错误。
3. 有服务器文件权限时，检查报错中的实际目录；截图中的 `data/default-user/extensions/-` 位于 **运行 SillyTavern 的机器**，手机访问云酒馆时不在手机文件里。该目录根层应至少有 `manifest.json`、`index.js`、`纯音乐播放器.js`、`style.css`，不要再套一层仓库文件夹。若是完整 Git 仓库，核对远端确为本仓库后更新它；若是残留或不完整目录，先停止酒馆，将该目录整体移到 `extensions` 外备份，再启动酒馆，用原链接和原安装范围重新安装。
4. 只能使用云酒馆网页、无法管理服务器文件时，让服务提供方检查并修复这个目录。不要用「给所有人安装」绕过「只给我安装」的冲突：同名用户扩展会优先于全局扩展，残留目录仍可能造成遮蔽。

仓库更新无法直接修复用户服务器上缺失清单的残留目录。处理安装目录时无需清除浏览器站点数据；播放器的收藏、歌单和陪听记录保存在浏览器中，清除站点数据反而会丢失这些记录。

## 使用说明

### 顶部按钮

- **×**：关闭播放器，之后可以从 SillyTavern 的扩展菜单重新打开。
- **标题「Selene Music」**：点击缩成迷你封面，再点迷你封面恢复；长按可以拖动播放器。
- mini 悬浮封面不会显示关闭叉；点击 mini 封面会恢复播放器，不会误关闭。
- **标 / 小 / 大**：切换播放器内容和按钮的大小。
- **词**：打开歌词设置，可统一开关悬浮歌词。
- **📌**：固定播放器，防止误拖动或缩放。
- **✦**：打开外观卡片，预览并切换皮肤；专辑玻璃排在第一位，是新安装的默认外观，已有用户保留自己选择的皮肤。
- **⚙**：打开详细设置。

Chrome 平板等触控设备会为关闭与外观按钮启用独立轻触处理，避免窗口拖动手势吞掉点击。魔法棒扩展菜单即使晚于播放器动态创建或被 SillyTavern 重新渲染，也会自动补回“音乐播放器”入口。

v2.10.22 为播放器顶部操作栏使用独立样式标识，避免酒馆主题的 `header`、`.head`、`.close` 样式让关闭按钮变大或遮住其余操作。顶部六个按钮保持紧凑尺寸，在窄屏和调大内容按钮时仍可显示；正文继续使用所选尺寸。窗口、标题长按及角色陪听拖动按动画帧合并触摸事件，陪听窗在拖动中使用位移预览、松手后保存位置，并在移动期间暂时减少毛玻璃重绘。

v2.10.23 将主界面整理为“喜欢 / 歌单 / 队列 / 陪听”四个入口，其他功能由右侧 **···** 打开。歌曲行只保留收藏与 **··· 更多操作**，音源、缓存、入队与删除仍可从菜单使用；歌词与播放控制留在底部，歌曲列表独立滚动。统一了圆角按钮、细线工具图标和设置开关；设置页的背景、卡片与输入控件跟随播放器皮肤配色。扩展控制栏新增 **与其他应用播放**，可选择优先播放或允许同时播放，并与播放器内设置双向同步。

v2.10.25 同时整理了 **··· 更多功能**：仅保留 **本层推荐 / 读取推荐 / 离线歌曲 / 歌词锁定**。喜欢、歌单、队列、陪听统一使用上方导航；缓存统一从歌曲右侧菜单操作。空封面使用独立占位图，不再显示浏览器空图片的白色边缘。

### 流光唱片样式

v2.10.24 新增 **✦ 外观 → 流光唱片**。v2.10.25 将封面改为真正的圆形裁切，外圈加入呼吸起伏、顺向流光与反向细光带，配合缓慢旋转的封面和随当前封面变化的柔化背景。音乐实际播放时旋转，暂停、缓冲或播放结束时停住；系统开启减少动态效果时显示静态唱片。无封面歌曲显示渐变占位。

- 点击 **找歌 / 歌单** 打开搜索、喜欢、歌单、队列与陪听入口，点击 **返回唱片** 或按 Esc 回到唱片。播放控制始终保留。
- 点击专辑封面可进入沉浸模式；标题仍可缩成迷你封面，支持手机、平板和桌面窗口。
- 随时通过 **✦** 切回其他皮肤；外观选择会保存在当前浏览器，刷新后仍然生效。

### 找歌与播放

- **搜索框**：在「⚙ 设置 → 搜索入口」切换入口，选择会自动保存。GD 音乐按网易云、JOOX 顺序补充候选，指定歌手的准确结果排在前面。其他音乐提供 QQ 音乐搜索，播放使用 LX Music 和 Meting 返回的 QQ 歌曲 ID。
- **B站网页**：在设置的「搜索入口」选择「B站网页」，在原搜索框输入关键词可打开 Bilibili 官方搜索，输入 BV 号或 B 站视频详情页直链可打开完整视频页。拖动标题栏可以移动窗口，使用 − 和 + 调整大小。桌面端也可拖动任意一角独立调整宽高，尺寸和位置会保留。浏览器若限制嵌入，可点击「在 B站打开」。打开浮窗时，当前音乐会继续播放。
- **BV 视频播放**：将 BV 号或 B 站视频链接复制到「GD 音乐」搜索框。点击识别出的视频条目会默认收起画面并尝试播放声音，也可以在条目菜单中选择「观看视频」或「在 B 站打开」。浏览器若拦截有声自动播放，可以打开画面后在 B 站播放器内点播放。
- **歌单播放**：点歌单里的歌曲，从该首开始播放整张歌单。上一首、下一首和自动续播跳过视频条目，视频可在列表中单独打开。
- **本层推荐**：读取当前楼层 AI 回复中的歌曲推荐，并自动搜索；同一聊天最近 30 个推荐楼层里已经出现过的同歌同歌手会被程序跳过，刷新后仍可直接从聊天记录恢复去重依据。
- **读取推荐**：读取当前角色或已导入世界书中的作者推荐歌单。
- **点击歌曲整行**：立即播放。
- **当前歌曲右侧爱心**：不再显示外圈；空心表示未收藏，点击后变成中国红实心，再次点击可取消收藏。
- **☆**：收藏或取消收藏歌曲。
- **＋**：将歌曲加入播放队列。
- **歌单**：将歌曲加入已有歌单，或直接创建新歌单。
- **⇩**：下载歌曲到浏览器本地缓存，供无网时播放。

### 收藏、歌单与播放队列

- **喜欢**：打开收藏歌单，映射红心收藏且不复制歌曲；可以查看、一键播放、加入队列或取消收藏。
- **我的歌单**：集中显示自建歌单和从音乐平台导入的歌单。歌单右侧的三点菜单可以 **一键加入队列**，按歌单顺序追加尚未入队的歌曲。打开歌单后点击 **批量管理**，可逐首多选或全选，再统一播放、入队、加入其他歌单、离线缓存或移出。
- **加入歌单**：搜索结果、收藏、歌单、队列和离线歌曲里的单曲都可从右侧三点菜单添加。
- **一键播放**：从第一首开始连续播放当前歌单。
- **队列**：查看接下来要播放的歌曲，数字代表当前队列数量。
- **×**：从收藏歌单中取消收藏，或从自建歌单、播放队列中移除歌曲。
- 删除单首歌曲或清空列表前都会显示确认提示，避免误触。
- 队列歌曲旁的 **☆**：将这首歌保存到收藏。

### 自建歌单与离线歌曲

- 点击顶部 **歌单** 可以导入、新建、查看、播放和删除独立歌单；收藏歌单由顶部 **喜欢** 进入。
- 在搜索结果、收藏、队列或歌单中点击 **歌单**，可以把歌曲加入指定歌单。
- 点击歌曲右侧 **··· → 下载离线缓存**，会将音频保存到浏览器的 IndexedDB；搜索结果与部分列表也可直接点击 **⇩**。
- 缓存和播放会独立判断音源可用性。缓存当前歌曲时优先使用浏览器已经成功加载的 `audio.currentSrc`；普通候选出现 403、404 或 410 后，会用 `cache: no-store` 和唯一防缓存参数强制刷新 GD 搜索及 320/128k 临时地址，再静默重试各平台。只有全部自愈流程失败后才显示错误；CORS、防盗链、空文件及存储空间不足仍会给出不同提示，缓存失败不会中断正在播放的歌曲。
- 点击 **离线歌曲** 可以查看、播放和删除缓存；播放器断网时会优先读取本地缓存。
- 离线缓存占用浏览器为当前站点分配的存储空间。在播放器中删除缓存不会影响收藏或歌单；清理整个浏览器站点数据则会连同播放器设置一起删除。

### 播放模式

底部右侧的播放模式按钮每点一次就切换模式，并提示当前模式。

- **双箭头循环**表示顺序循环，播到末尾后回到第一首。
- **带 1 的循环箭头**表示单曲循环，重复当前歌曲。
- **交叉箭头**表示随机播放。

### 歌词

- **歌词锁**：点击播放器顶部的锁可锁定或解锁悬浮歌词位置。
- 歌词解锁时，可以拖动悬浮歌词。位置和字号会自动保存。
- **词**：打开歌词设置。电脑和手机共用「悬浮歌词」开关，渐变文字默认开启。播放时显示当前句和译文，没有译文时第二行预览下一句。
- 点击歌曲封面可以进入大封面沉浸模式，再次点击封面或右上角箭头即可返回。

### 播放控制

- **‹‹**：上一首。
- **-10**：后退 10 秒。
- **▶ / ❚❚**：播放或暂停。
- **+10**：前进 10 秒。
- **››**：下一首。
- **进度条**：拖动跳转到歌曲的指定位置。
- **音量条**：调节播放器音量。

播放器只有在音频真正进入可播放状态后才会显示播放成功；仅仅接受了浏览器播放请求、但仍无时长无声音的失效链接会被判定失败并自动切换备用音源。本层推荐还会优先播放同时严格匹配歌名和歌手的搜索结果，不再直接拿结果列表第一条。

### 角色陪听

点击播放器里的 **角色陪听**，会打开一个独立的双人听歌空间。它会读取当前 SillyTavern 角色卡中的描述、性格、场景、作者备注与示例对话，也会参考最近的主聊天、当前歌曲和正在显示的歌词；陪听窗里的消息及专属记录按角色分别保存在浏览器本地，不会写进 SillyTavern 主聊天。

角色陪听完整窗口可以拖动顶部栏或人物头像移动；轻点头像仍会缩成悬浮球，拖动后的位置会按桌面端与触控设备分别保存。悬浮球松手后会吸附到最近的左右边缘，并记住拖动的高度；打开陪听再缩回时会回到原来的位置。

如果当前角色卡描述或其绑定世界书里识别出至少两位明确人物，角色陪听会进入小手机式消息首页。自动扫描会同时读取角色卡已保存的描述和当前编辑页的 `description` 输入框；支持“姓名：陆淮安”“原男主：陆淮安”“陆淮安（原男主）”以及“陆淮安的态度”这类写法，并把角色描述中命中姓名附近的设定保存为该联系人的陪听人设。属性/身份标签本身不会成为联系人：“心腹”“原男主”“关键记忆”“客观状况”“语言风格”“阶段”“觉醒时间节点”“性观念”等会被排除，“陆淮安的态度”只会识别为“陆淮安”。世界书扫描采用独立的严格人物档案判定：条目必须先出现人物/角色档案结构、明确姓名字段，或至少两类成组的人设字段，才允许用标题和关键词判断档案归属；关键词里只有人名的剧情、事件、状态、关系推进和记忆条目不会创建联系人，也不会计入关联人设来源。扫描器只用当前 char 本身及其实际绑定世界书发现人物，不会用全局世界书扩充联系人名单。升级后会自动重扫并移除旧版误识别的自动联系人；“重新扫描人物”会强制清空并重建全部自动联系人、关联来源和自动提取人设，同时保留手动人物、改名、头像、备用头像字、聊天记录及仍然有效的群聊。播放器会从人物档案条目的头像字段、图片或立绘链接读取真实头像；没有图片时才使用名字末字作为备用头像，撞字时自动改为最后两个字。

- **小手机会话页**：角色陪听会像消息应用一样显示联系人和已经建立的群聊，点击会话进入聊天，聊天页可一键返回会话列表。
- **私聊**：点击联系人进入对应人物的独立对话；每个人拥有独立聊天记录、专属歌单、音乐记忆和陪听时长统计。角色回复会显示对应头像，不再把“角色名：”重复塞在消息正文里。
- **自建群聊**：点击 **＋ 建群**，填写群名并勾选至少两位人物即可拉群；群成员、群名和群头像可随时修改。每个固定群拥有自己的稳定聊天记录，只加载该群成员的人设。
- **手动头像**：联系人管理中可上传人物头像，群设置中可上传群头像。图片会在浏览器内自动压缩并保存在当前浏览器，不需要图床；原有 URL、角色头像文件名和世界书图片仍然支持。
- **@ 定向发言**：输入 `@角色名` 或同时 `@` 多人，本轮只允许被点名人物回应；手机端长按头像、电脑端右键头像会直接在输入框插入 `@角色名`。桌面右键在捕获阶段处理，避免被 SillyTavern 的右键菜单拦截。不带 `@` 时由模型依据人物关系自然决定谁接话，不强制所有人逐个发言。
- **联系人管理**：可以查看识别人物和关联世界书条目、改名、上传本地头像、修改头像地址或备用头像字、删除误识别、手动添加遗漏人物并重新扫描。
- 当前歌曲和播放器状态为共享信息；私聊与不同群聊组合的记录彼此隔离，私人对话不会自动泄露给其他人物。

点击角色头像可将陪听窗缩成独立的小型圆形头像悬浮球，再次点击恢复。完整窗口可拖动标题栏，悬浮球可直接按住头像拖动；两种模式分别记忆位置，窗口尺寸或屏幕方向变化时会自动留在可视区域。陪听窗采用 iMessage 风格的居中头像、蓝色发送气泡与半透明接收气泡；私聊不在消息旁重复显示头像，群聊保留人物头像与名字。同一人物连续发送的短句只在最后一个气泡显示短尾。打开陪听窗的 **设置 → 聊天背景**，可选择歌曲封面、纯白、深色，或上传本地图片、填写图片链接；本地图片会自动压缩并保存在当前浏览器，接收气泡会透出背景。点击 **恢复默认** 可清除自定义图片并恢复歌曲封面。标题区域不显示 API 或模型名，而会在每次打开时随机给出一个角色心情；心情只作为角色化反应的轻提示，不会覆盖角色卡中已经成立的情绪。

陪听支持两种生成方式：

- **自定义 OpenAI 兼容 API（默认）**：在陪听窗点击 **设置**，填写 API 地址、模型名和 API Key。地址可以填写服务根地址、以 `/v1` 结尾的地址，或完整的 `/chat/completions` 地址。点击 **获取列表** 会读取兼容接口的 `/v1/models`；获取后可以直接选择模型，也可以继续手动填写。无鉴权的本地兼容接口可以不填 Key。
- **SillyTavern 当前角色与当前模型**：调用 SillyTavern 的 `generateQuietPrompt()`，沿用当前角色、主聊天上下文与已经选择的模型，不需要额外 API 或 Key，也不会把陪听回复发送到主聊天。
- 自定义 API 的 **获取列表** 会直接展开接口返回的全部模型，不会被输入框里已有的模型名过滤；当前模型名会保留，也可以点击输入框右侧箭头重新打开完整列表。

两种模式都严格只读取当前角色卡实际绑定的世界书，以及 SillyTavern 世界书面板中当前全局启用的世界书。没有绑定或启用任何一本时会立即跳过，不查询世界书列表中的其他文件，也不会复用以前读取过的内容。有挂载项时只加载这些指定文件，再根据当前主聊天与陪听对话匹配常驻条目和触发词，最多发送约 12000 字符。SillyTavern 模式会关闭 `generateQuietPrompt()` 自带的宽范围 WIAN 注入，改用同一份严格结果，因此聊天绑定世界书、Persona 世界书和未挂载文件不会混入陪听提示词。

陪听设置默认启用 **原生真人私聊与去 AI 腔预设**。`REAL_CHAT` 拥有最高的可见形式优先级：角色与情绪只能决定回复方向，不能为了证明人物存在而增加句子、心理分析或氛围描写。日常问题默认一到两行，允许“嗯”“听歌呢”“刚看到”这类低信息回复完整结束，也不会自动追加“你呢”。短句通常不加句号，优先使用空格、换行或自然逗号；显示前还会强制清除破折号、装饰性省略号、分号和密集中文句号，同时保留点歌所需的隐藏结构行。它统一应用于手动聊天、自动回应、角色点歌和票根，可以展开编辑、关闭或恢复默认。旧版内置默认预设会安全升级，自行改写过的自定义预设会保留。

陪听空间提供以下互动：

- **我们的歌**：把当前歌曲收藏到与当前角色独享的双人歌单，可直接播放或移除。
- **音乐记忆**：记录第一次一起听、最近播放、累计次数、单曲循环和角色点歌次数。
- **陪听时长**：仅在角色陪听窗口开启且歌曲真实播放时累计，暂停、缓冲、拖动进度条和关闭窗口不会虚增；当前人物私聊与每个固定群聊分别显示累计、今天、近 7 天及陪听最久歌曲。
- **听后票根**：歌曲结束后由角色写一句评价并制作纪念票根；可手动生成，也可在设置中开启自动生成。
- **角色点歌**：角色综合角色卡、本轮激活的世界书、最近主聊天与陪听对话、当前场景、关系推进、角色心情和当前歌曲，自主提出一首真实歌曲。它会优先识别年份年代、地域文化与世界类型；古代中国、武侠、修仙/仙侠、西方古代、中世纪、西幻、未来、末世等设定会分别匹配更合适的真实曲目、器乐或影视/游戏原声，不再默认偏向欧美现代流行歌。每次只选一首并核对官方曲名和主要歌手/作曲者；原声会使用具体曲目搜索，自动去除括号中的影片名、“原声那一首”等说明。兼容“歌名/歌手”、JSON、书名号、裸竖线与横线等常见回复格式，每次点歌只向模型请求一次。搜索会先同时校验曲名和歌手，必要时再用净化后的曲名降级搜索，避免随机播放不相关结果。每位角色私聊与每个固定群聊会分别持久记录全部历史点歌：提示词避开最近 30 首，程序在播放前检查完整历史，若回复无法识别、歌曲重复、搜不到歌曲或无法播放，陪听窗旁会短暂弹出系统提示，可以手动再试一次；提示不保存到对话，也不发给模型；刷新网页后记录仍保留，只有用户本轮明确点名具体歌名时才允许再次播放。点击角色点歌或选择心情即视为播放授权，不再弹出二次确认；可见回复只保留一句自然短句，若模型仍输出“理由/匹配/语境”类分析将自动替换为口语回复。
- 在群聊或角色列表存在同名项时，陪听窗会优先按最近发言角色的头像精确识别角色，并只读取该角色实际挂载的角色世界书，避免 SillyTavern 弹出“找到多个角色”。
- **聊天点歌**：在对话里直接说“给我点首歌”“换一首”或“播放某某”，会被识别为播放授权；没有指定歌曲时同样按角色心情、人设和最新对话进行全网推荐，指定了歌名或歌手时则优先服从用户。用于搜索的结构化选歌行不会显示在聊天气泡中。
- **心情选歌**：选择开心、失眠、想念、治愈、浪漫、战斗、雨天或安静，角色会把心情与角色卡时代、世界观、文化背景和最新剧情结合后进行全网推荐；剧情与设定优先于泛化的心情歌单。选定心情后只向模型请求一次，失败时使用与角色点歌相同的临时系统提示。
- **歌词互动**：点击播放器当前歌词，或点击陪听窗的 **问这句歌词**，直接和角色讨论歌词。
- **双人模式**：角色可以建议重听或换歌，但不会替用户操作播放器。
- **TTS 语音反应**：复用 SillyTavern 已启用的 TTS 提供商和角色语音映射，通过 `/speak` 朗读陪听回复。

自动互动默认每首最多一次，也可设为两次。开启 **完全安静** 后会关闭切歌回应、中段互动、自动票根和 TTS，手动聊天仍然可用。

手机端陪听窗会使用紧凑悬浮尺寸和独立最高层级，避免被 SillyTavern 的回到底部按钮、顶部栏或消息输入框覆盖。

> 自定义 API Key、陪听对话、双人歌单、音乐记忆与陪听时长会保存在当前浏览器站点的 `localStorage` 中。自定义服务还需要允许 SillyTavern 所在网页跨域访问；若服务不允许 CORS，请改用 SillyTavern 当前模型模式或调整服务端跨域设置。

### 陪听窗口自动配色

陪听窗口会根据实际背景自动选择深色或浅色文字、输入框和下拉框。纯白和深色背景直接匹配，自定义图片与歌曲封面会在浏览器内采样明暗；图片无法跨域采样时跟随播放器当前配色。设置面板、说明文字、数字输入与模型选择框使用同一套配色，避免被酒馆主题改成深底黑字。

### 导入歌单

进入 **我的歌单**，点击标题右侧的 **导入歌单**，再粘贴支持的歌单链接：

- 网易云音乐歌单链接
- QQ 音乐歌单链接
- 酷狗音乐歌单链接

播放器会自动从完整分享文案中提取链接，包括普通文本、`[链接](链接)` Markdown 和 HTML 链接；Markdown 自动添加的 `\&` 等查询参数转义也会在解析前还原。播放器会识别链接来自网易云、QQ 音乐还是酷狗，并创建对应的独立歌单。网易云 `163cn.tv/...`、QQ 音乐 `c6.y.qq.com/base/fcgi-bin/u?__=...` 和酷狗 `t1.kugou.com/...` 分享短链会自动经过浏览器跨域通道或已启用的 SillyTavern 代理展开，不需要手动复制歌单 ID。网易云私人歌单受平台访问权限限制，需要先设为公开才能由播放器导入。单次最多导入 1000 首。再次导入同一平台的同一歌单时不会阻止重复导入，而会保留现有歌单名称和编号、用平台最新曲目顺序完整替换旧快照、更新歌曲信息、移除平台已经删除的旧歌，并自动合并旧版本留下的重复导入歌单；收藏歌单和其他自建歌单不受影响。

### 导入 MP3 与修复缺失音源

- 在 **我的歌单 → 导入 MP3** 中粘贴音频直链，填写歌名、歌手，再选择已有歌单或创建新歌单。进入具体歌单后也可点击 **导入 MP3**，直接添加到当前歌单；收藏歌单同样支持。
- 支持 `http(s)` MP3、M4A、OGG、WAV 等浏览器能播放的音频，以及不以 `.mp3` 结尾的带签名下载地址。链接需直接返回音频文件，音乐平台或网盘的分享页面需要先取得音频直链。
- 原来放不了的歌曲，点击歌曲右侧 **音源**，粘贴 MP3 直链即可补充或更换。手动音源会保存在收藏与歌单中，加入队列时也会保留，播放时优先使用；平台歌曲留空可清除手动音源，恢复自动找源。重新同步平台歌单时，同名同歌手歌曲的手动音源会保留。
- 导入平台歌单会保留接口返回的播放地址。地址失效后，播放器会逐一验证不同码率、备用接口和其他平台，不再因为某个接口给出的链接实际不可播放就提前停止切换。全部失败时会提示手动补音源。
- 歌曲右侧 **··· → 下载离线缓存**（或列表中的 **⇩**）仍可把直链歌曲下载为离线缓存；更换手动音源后再次缓存会更新旧缓存。播放和离线缓存分别受音源服务器的访问、防盗链、跨域及有效期限制，导入链接不会让失效或无权限的地址变成可播放。

### 世界书作者推荐歌单

仓库提供了可直接导入 SillyTavern 的 [`Selene作者推荐歌单-世界书模板.json`](./Selene作者推荐歌单-世界书模板.json)。导入后可将世界书绑定给角色，也可以作为普通世界书保存；点击播放器中的 **读取推荐** 即可读取。

世界书条目可以保持禁用，避免歌单内容进入聊天提示词。播放器会读取 `<selene_playlist>` 专用标签，不会把世界书的普通正文误识别成歌曲。

作者只需按下面的格式填写歌名和歌手，每首歌占两行：

```text
<selene_playlist>
歌单名：角色名的推荐歌单

歌曲：Too Much
歌手：Dove Cameron

歌曲：微醺夜
歌手：Veena
</selene_playlist>
```

也支持一行简写：

```text
<selene_playlist>
Too Much | Dove Cameron
微醺夜 | Veena
</selene_playlist>
```

请保留开头与结尾的 `<selene_playlist>` 标签。读取成功后，可以逐首播放、收藏或加入队列，也可以点击 **全部入队** / **一键播放**。

### 设置里的功能

- **自动读取推荐**：AI 回复中出现歌曲推荐时，自动搜索并播放。
- **系统媒体保活**：未选中任何歌曲时运行静音媒体，并在锁屏、控制中心或状态栏中显示 `SillyTavern` 和内置专辑图；选中歌曲后，播放和暂停状态都由歌曲独占系统媒体卡片，避免静音保活抢走播放按钮。扩展版使用内置 AAC，脚本版使用兼容的 44.1kHz WAV。
- **后台请求续跑**：角色陪听忙时发送的新消息会按顺序排队，不再丢弃；页面从冻结中恢复或回到前台时会继续队列与被中断的播放。隐藏页面的音源重试不再等待容易被限流的定时器。
- **与其他应用播放**：默认使用“优先播放”，在支持 Audio Session 的浏览器中请求 `playback` 音频会话，并在非手动中断后尝试恢复；切换“允许同时播放”后请求 `ambient` 混音，让支持该接口的系统尝试与其他应用共播。
- **回到保活**：扩展设置栏中的手动切换按钮。点击后暂停当前歌曲并让静音媒体接管；下次从播放器播放歌曲时，静音保活会自动让位。
- **主题**：切换跟随系统、日间或夜间模式。外观选择、歌词设置和播放源弹窗共用播放器当前皮肤的背景、文字与强调色；专辑玻璃和流光唱片还会同步柔化的封面背景。
- **搜索入口**：GD 音乐（默认）、其他音乐或 B站网页。
- **GD 搜索音源**：自动、网易云或 JOOX，适用于 GD 音乐。播放键左侧的 **双箭头图标** 可为当前歌曲手选音源或恢复自动回退。离线缓存和手动 MP3 保留优先级。
- **界面规格**：小巧、标准或宽屏，取代原来的顶部“标”按钮。
- **独立尺寸调整**：分别修改按钮、文字、封面和歌曲列表的大小。
- **恢复播放器默认尺寸**：播放器窗口大小乱掉时一键恢复。
- **修复与重置 → 清空播放器缓存**：确认后停止播放，清理搜索、歌词、临时音频地址和下载的离线歌曲，取消旧请求；保留收藏、歌单、手动音源与陪听数据。清理缓存不会重置 GD 或备用服务的限流时钟。
- **修复与重置 → 恢复默认设置**：确认后恢复播放器外观、位置、歌词、音源与播放偏好，保留收藏、歌单、离线歌曲、陪听模型配置与记录。

### 右上角「词 / 锁」设置浮窗

顶部使用共用椭圆背景的 **词 / 锁** 两个独立按钮。**词** 打开独立歌词设置，**锁** 直接锁定或解锁歌词位置。打开菜单不会直接开关歌词。电脑和手机共用悬浮歌词开关，可分别调整字号，也可设置位置锁定、主色与渐变副色并预览。**重置位置与字号** 会恢复默认歌词位置和大小。歌词选项集中在这个浮窗中，皮肤与歌词浮窗互斥，浮窗按可用空间滚动并避开顶部按钮。

v2.10.33 同时修复窗口拖动：窗口挂到最外层可访问的同源父页面，标题移动超过小阈值即可拖动，仍可轻点缩成迷你封面。一次动画帧只处理最新移动，视口变化不覆盖拖动中的坐标，松手提交最后位置；取消拖动保留已显示的位置，拖动不会改变窗口尺寸。

### Selene 扩展控制栏

在 SillyTavern 的扩展设置页中展开「Selene 音乐播放器」，可以：

- 展开控制栏后，可在内容右下角查看当前插件版本。
- 显示或隐藏播放器窗口。
- 显示或隐藏角色陪听窗口。
- 选择启动 SillyTavern 时是否自动显示播放器。
- 插件版默认在扩展菜单显示「音乐播放器」入口，并允许在这里关闭或重新开启；入口采用与新版 SillyTavern 一致的容器结构，并固定为图标和文字单行排列。
- 单独导入的脚本版会始终保留扩展菜单入口，无法关闭，点击播放器的 **×** 隐藏后可随时从这里重新打开。
- 脚本版可在播放器的齿轮设置标题旁查看当前版本。
- 启用或停止系统媒体保活，并查看是否已经真正开始播放。
- 在 **与其他应用播放** 中切换优先播放或允许同时播放，与播放器设置同步；不支持 Audio Session 的浏览器仍会保存偏好，并显示兼容说明。
- 在支持 Media Session 的浏览器中，锁屏或控制中心会显示当前歌曲、歌手、专辑封面、真实时长与进度，并可播放、暂停、切换歌曲或拖动进度。
- 播放器会在真实音频开始播放、封面更新及页面回到前台时重新提交歌名与歌手，减少 Chrome 控制中心只显示应用名称的问题。
- Android Chrome、Android/Windows Edge 与 iOS Safari 均可通过浏览器的 Media Session 接入系统媒体界面；首次播放必须由用户点击歌曲或播放键触发。部分安卓系统还需要允许浏览器通知、后台活动并关闭严格省电限制。
- 设置面板会直接显示当前浏览器是否检测到 `navigator.mediaSession`；这可用于检查雨见等采用不同内核的浏览器版本。
- 分别重置播放器位置与窗口尺寸。
- 重置角色陪听窗口位置；桌面、手机、完整窗口与头像悬浮球的位置会一起恢复到当前屏幕内的默认位置。

### 系统媒体保活怎么开

可以从「Selene 音乐播放器」扩展控制栏开启，也可以在播放器中打开：

**⚙ → 系统媒体保活 → ▶ 启动保活**

开启后会在尚未选中歌曲时播放本地静音媒体，并以 `SillyTavern` 名称和内置专辑图显示在锁屏、控制中心或状态栏。一旦选中歌曲，静音保活就会让位，即使歌曲处于暂停状态也不会抢走系统媒体卡片。状态栏的播放按钮会恢复当前歌曲。如果浏览器没有自动开始，扩展控制栏会显示原生音频播放条，点击其中的播放键即可。

显示 **系统媒体已播放** 或 **系统媒体已启动** 就代表已经开启。iPhone/iPad 切到后台后，控制中心或锁屏界面可能显示 Chrome/SillyTavern 的媒体控制；不需要时可以点击 **■ 停止保活**。

> 系统媒体保活可以降低浏览器休眠导致暂停播放或掉线的概率，但如果手机系统直接冻结或关闭浏览器，网页无法保证百分之百不断线。

> 手机软键盘弹出时，Selene 会保留键盘出现前的播放器与陪听窗高度，不再把缩小后的可视区域误当成新屏幕尺寸。

> “优先播放”和“允许同时播放”是两种不同的系统音频策略：前者更积极地争取媒体焦点，后者允许混音。网页扩展不能越过 Android/iOS 强制获得永久最高优先级，实际行为仍取决于浏览器内核、系统省电策略和厂商限制。

仓库发布新版本后，可以在 SillyTavern 的扩展管理界面中检查并安装更新。

插件版适配 `SillyTavern-Extension-Hot-Reload` 的生命周期与自管理模块协议。v2.10.25 为入口加载的播放器模块及保活音频、封面统一附加发布版本和 `st_hot_reload` 标记，支持安全与强制策略直接热载入，避免计算路径动态导入被模块图预检拦截。更新时会等待正在加载的模块结束，完整卸载旧窗口、音频、菜单、观察器和事件，再创建新实例；重复激活不会创建重复窗口。禁用后重新启用同样会载入新的运行实例，收藏、歌单和外观设置保留。

## 数据来源与使用说明

- **音乐与歌词数据**：[GD 音乐台](https://music.gdstudio.xyz)。备用同步歌词来自既有 Meting 接口与 [LRCLIB 官方 API](https://lrclib.net/docs)，仅发送歌曲元数据，不发送聊天、角色卡或模型配置。
- v2.10.33 保留宽松的手动搜索：支持只输入歌手、部分歌名、关键词或记忆中的近似歌名，展示接口返回的候选，不要求输入与歌曲元数据完全一致。点击歌曲后，以选中的歌名、歌手和版本严格匹配播放及备用音源；自动推荐与自动选歌仍按明确的请求严格筛选。
- 默认搜索和自动推荐按 **网易云 → JOOX** 顺序按需进行；搜索来源独立于播放来源，可用播放区的双箭头图标为当前歌曲单独指定来源。手动搜索保留模糊候选；明确指定歌手时，若当前来源只有翻唱则继续查下一来源。仅输入歌名时会顺序补充各来源结果，避免网易云的非空结果遮住 JOOX。设置中可直接指定搜索来源；自动选歌在符合指定身份时停止搜索，播放验证成功后停止切源。离线缓存与用户手动 MP3 保留优先级。
- 歌手按完整身份匹配（支持周杰伦、周杰倫、Jay Chou 的明确别名），同时核对歌名、专辑版本和可用时长。拒绝用同名翻唱、DJ、伴奏或试听替换指定版本；用户明确搜索 Live、翻唱或 Remix 时保留该版本。元数据不足时不宣称“原唱”。
- v2.10.36 放宽歌手显示格式：兼容简繁体常见别名、括号英文名、重复中英文署名和合作歌手分隔符；额外合作歌手须有时长证据，完整署名优先。音频时长允许少量片头片尾差异，跨源歌词仍使用更严格的版本与时长校验。
- v2.10.40 搜索封面随列表滚动加载，播放页获取的封面同步给同一首歌或同一平台专辑图 ID 对应的结果。缺图时隐藏缩略图边框，保留行布局。已有可用封面直接复用，其他封面优先使用自建 Selene Meting，再尝试公共 Meting 和 GD。按歌名、歌手、版本及可用专辑信息核对封面。
- Safari 在用户手势内，用独立的 100ms 本地 PCM 音频对同一主音频元素申请播放授权，异步读取缓存及解析音源后再加载歌曲；主播放器不再使用十小时后台保活文件预热，也不会把其 `600:00` 时长展示为歌曲时长。实际歌曲切换不再额外调用 `load()` 打断资源加载，授权拒绝时允许再次点击直接播放已解析地址。Safari 原生网络或无进度错误可进行一次 CORS 允许的 Blob 播放重试，不新增代理。只有媒体时间连续推进才显示正在播放；短暂 `waiting` / `stalled` 显示缓冲，前台持续 20 秒无进度或发生音频错误才尝试备用源。拒绝授权时等待用户再次点击，不消耗整轮音源；暂停、切歌或卸载取消旧验证，后台定时器节流不触发切源。一次选曲最多执行一次播放开始后的卡顿恢复。
- 每个音源先请求 320k；网易云按需尝试 128k，JOOX 按文档覆盖 192k、128k、740 和 GD 默认 999 音质的有界回退，并跳过重复地址。搜索返回的 track ID 原样传给取音频地址接口，不擅自去除前缀，也不使用已废弃的 `url_id` 代替它。解析支持嵌套、数组与协议相对 URL，保留签名参数；同时读取 GD `extra_data.duration` 参与版本校验。GD 搜索保留一分钟缓存；播放地址仅合并同时进行的请求，不缓存成功或空地址响应。v2.10.41 移除 Selene 本地的请求次数拦截，播放、搜索、封面和歌词遵循 GD 自身的限流响应。收到 GD 限流后停止同一服务内的回退，同一冷却期只弹出一次播放提示。
- v2.10.41 恢复 v2.10.39 的播放回退范围。每个 GD 来源最多尝试三条严格匹配记录，JOOX 的备用记录也可尝试全部五档音质，首条记录最多额外刷新一次 URL，每轮最多 16 次 JOOX 取址。成功立即停止，HTTP、传输及接口异常停止该来源的后续请求，限流停止所有 GD 来源。重播时优先以该曲上次成功的音质获取新地址。解析中的同曲同来源重复 `play()` 共用一轮结果和一次失败提示。
- v2.10.43 在 JOOX 取址发生临时网络错误、超时或 HTTP 5xx 时，对同一曲目 ID 和音质额外刷新一次。每轮 JOOX 共用一次传输错误重试机会，GD 限流直接停止。F12 的 `window.__SELENE_GD_DIAGNOSTICS__` 保留近期 GD 请求及拦截记录。GD 限流条目记录近期发起的请求数、HTTP 状态和可重试时间，近期请求数仅供诊断。音频候选错误和整轮失败另在控制台保留原始错误与媒体状态。
- v2.10.45 对 GD 的 HTTP 502/503/504 和 fetch 抛出的未分类 `TypeError` 最多做三次带抖动的退避重试。共享的四秒故障窗口内，后续请求只探测一次，收到非 5xx 响应即清除窗口。封面请求只尝试一次。播放取址遇到 HTTP 5xx 会提示「上游服务暂时不可用，非本曲问题」，结束当前音源并尝试下一音源。HTTP 429、JSON 限流和 HTTP 200 空播放地址继续走各自的处理路径。
- v2.10.54 导入时保留歌手、专辑、时长和版本。跨平台找播放地址时允许「官方音频」等标题格式差异；候选缺少 Live 或翻唱标记时，仍需歌手和时长或专辑能对上才会采用。自动推荐和歌词继续使用原有匹配规则。
- 支持的来源优先使用自建 Selene Meting 的签名歌词，核对平台和歌曲 ID 后才采用。公共 Meting、GD 和 LRCLIB 依次补位。JOOX 歌词使用 GD，失败时可用 LRCLIB 按歌名、歌手、版本和实测时长严格匹配。Meting 和 LRCLIB 请求独立于 GD 额度。
- v2.10.35 失败提示保留各来源的尝试结果，不再被最后一个备用源覆盖；区分接口未返回播放地址、未找到同歌手版本、网络请求与音频播放错误。不存在匹配歌曲时停止该来源的后续音质请求。
- 切源同时更新平台、歌曲 ID、音频、专辑、封面和歌词 ID；离线播放使用缓存对应的元数据。保留双语歌词、实际 LRC 时间轴、沉浸歌词与悬浮歌词的校验及同步。
