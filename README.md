# Selene 音乐播放器

一个可通过 Git 仓库链接直接安装的 SillyTavern 第三方音乐播放器扩展。

## 功能

- 搜索和播放网络音乐
- 歌词显示与桌面悬浮歌词
- 播放队列、歌曲收藏与自建歌单
- 歌曲下载缓存与离线播放
- 导入网易云、QQ 音乐或酷狗歌单
- 读取世界书中的作者推荐歌单
- 自动读取 AI 回复中的歌曲推荐
- 双人角色陪听空间（独立聊天、专属歌单、音乐记忆与听后票根）
- 可切换 SillyTavern 当前模型或自定义 OpenAI 兼容 API，并获取模型列表
- 多种皮肤、迷你模式与沉浸模式
- 播放器和歌词尺寸自定义
- 系统媒体保活
- 桌面端与移动端适配

## 安装

1. 打开 SillyTavern，点击顶部的「扩展」。
2. 选择「安装扩展」。
3. 粘贴本仓库的 HTTPS 链接：

   ```text
   https://github.com/soso454u/-
   ```

4. 点击安装，安装完成后会立即加载并显示播放器，不需要手动刷新。若不成功按照 SillyTavern 的提示重新加载页面。

> 请不要粘贴 `raw.githubusercontent.com` 文件链接、ZIP 下载链接或单个 JS 文件链接。SillyTavern 需要的是完整 Git 仓库链接。

## 使用说明

### 顶部按钮

- **×**：关闭播放器，之后可以从 SillyTavern 的扩展菜单重新打开。
- **标题「Selene Music」**：点击缩成迷你封面，再点迷你封面恢复；长按可以拖动播放器。
- mini 悬浮封面不会显示关闭叉；点击 mini 封面会恢复播放器，不会误关闭。
- **标 / 小 / 大**：切换播放器内容和按钮的大小。
- **词**：开启或关闭桌面悬浮歌词。
- **📌**：固定播放器，防止误拖动或缩放。
- **✦**：切换播放器皮肤。
- **⚙**：打开详细设置。

### 找歌与播放

- **搜索框**：输入歌曲名或歌手，点击搜索。
- **读取本层推荐**：读取当前楼层 AI 回复中的歌曲推荐，并自动搜索。
- **读取推荐**：读取当前角色或已导入世界书中的作者推荐歌单。
- **点击歌曲整行**：立即播放。
- **☆**：收藏或取消收藏歌曲。
- **＋**：将歌曲加入播放队列。
- **歌单**：将歌曲加入已有歌单，或直接创建新歌单。
- **⇩**：下载歌曲到浏览器本地缓存，供无网时播放。

### 收藏与播放队列

- **收藏**：查看已经保存的歌曲。
- **收藏入队**：将全部收藏歌曲加入播放队列。
- **一键播放**：从第一首开始连续播放收藏歌曲。
- **队列**：查看接下来要播放的歌曲，数字代表当前队列数量。
- **×**：从收藏或播放队列中删除歌曲。
- 删除单首歌曲或清空列表前都会显示确认提示，避免误触。
- 队列歌曲旁的 **☆**：将这首歌保存到收藏。

### 自建歌单与离线歌曲

- 点击 **我的歌单** 可以新建、查看、播放或删除自建歌单。
- 在搜索结果、收藏、队列或歌单中点击 **歌单**，可以把歌曲加入指定歌单。
- 点击歌曲旁的 **⇩**，或播放歌曲后点击 **缓存当前**，会将音频保存到浏览器的 IndexedDB。
- 点击 **离线歌曲** 可以查看、播放和删除缓存；播放器断网时会优先读取本地缓存。
- 离线缓存占用浏览器为当前站点分配的存储空间。在播放器中删除缓存不会影响收藏或歌单；清理整个浏览器站点数据则会连同播放器设置一起删除。

### 播放模式

点击播放模式按钮可以循环切换：

- **循环 ↻**：按照顺序循环播放。
- **单曲 ↺**：重复播放当前歌曲。
- **随机 ⤨**：随机播放歌曲。

### 歌词

- **歌词 🔓**：歌词可以拖动。
- **歌词 🔒**：锁定歌词位置，防止误触。
- 歌词解锁时，拖动悬浮歌词右下角的 **↘** 可以放大或缩小歌词；位置和大小会自动保存。
- **词**：快速开启或关闭桌面悬浮歌词。
- 手机版可以在设置中单独开启悬浮歌词。
- 点击歌曲封面可以进入大封面沉浸模式，再次点击封面或右上角箭头即可返回。

### 播放控制

- **‹‹**：上一首。
- **-10**：后退 10 秒。
- **▶ / ❚❚**：播放或暂停。
- **+10**：前进 10 秒。
- **››**：下一首。
- **进度条**：拖动跳转到歌曲的指定位置。
- **音量条**：调节播放器音量。

### 角色陪听

点击播放器里的 **角色陪听**，会打开一个独立的双人听歌空间。它会读取当前 SillyTavern 角色卡中的描述、性格、场景、作者备注与示例对话，也会参考最近的主聊天、当前歌曲和正在显示的歌词；陪听窗里的消息及专属记录按角色分别保存在浏览器本地，不会写进 SillyTavern 主聊天。

点击角色头像可将陪听窗缩成独立的圆形头像悬浮球，再次点击恢复。完整窗口可拖动标题栏，悬浮球可直接按住头像拖动；两种模式分别记忆位置，窗口尺寸或屏幕方向变化时会自动留在可视区域。陪听窗会跟随播放器当前皮肤，并将歌曲封面作为模糊氛围背景。

陪听支持两种生成方式：

- **自定义 OpenAI 兼容 API（默认）**：在陪听窗点击 **设置**，填写 API 地址、模型名和 API Key。地址可以填写服务根地址、以 `/v1` 结尾的地址，或完整的 `/chat/completions` 地址。点击 **获取列表** 会读取兼容接口的 `/v1/models`；获取后可以直接选择模型，也可以继续手动填写。无鉴权的本地兼容接口可以不填 Key。
- **SillyTavern 当前角色与当前模型**：调用 SillyTavern 的 `generateQuietPrompt()`，沿用当前角色、主聊天上下文与已经选择的模型，不需要额外 API 或 Key，也不会把陪听回复发送到主聊天。

两种模式都会使用当前启用且被本轮聊天触发的世界书内容。SillyTavern 模式沿用正常生成链中的世界书扫描；自定义 API 模式会调用 `getWorldInfoPrompt()` 做只读 dry-run，并合并本轮激活的 Before、After、深度、示例和作者注释条目，最多发送约 12000 字符，避免整本世界书无条件占满上下文。

陪听设置默认启用 **微信式真人聊天与去 AI 腔预设**。普通问题会优先直接短答，线上聊天默认只输出对话；角色感来自选择、忽略、追问、误解、拒绝与保留，不再依赖括号动作、哲理反问或每句都“表演人物”。预设还会约束角色的欲望、自利、矛盾、情绪余波、行动力与关系边界，并检查套话、空泛意象、解释性复述、视角越权和常见 AI 八股句式。它统一应用于手动聊天、自动回应、角色点歌和听后票根，可以展开编辑、关闭或一键恢复内置版本。旧版内置默认预设会自动升级，完全自定义的预设会保留。

陪听空间提供以下互动：

- **我们的歌**：把当前歌曲收藏到与当前角色独享的双人歌单，可直接播放或移除。
- **音乐记忆**：记录第一次一起听、最近播放、累计次数、单曲循环和角色点歌次数。
- **听后票根**：歌曲结束后由角色写一句评价并制作纪念票根；可手动生成，也可在设置中开启自动生成。
- **角色点歌**：角色根据当前剧情，从收藏、普通歌单与“我们的歌”中选择，用户确认后才会播放。
- **聊天点歌**：在对话里直接说“给我点首歌”“换一首”或“播放某某”，会被识别为播放授权；角色选歌后自动匹配已有歌曲，匹配不到时会搜索歌名和歌手并切换。用于执行动作的结构化选歌行不会显示在聊天气泡中。
- **心情选歌**：选择开心、失眠、想念、治愈、浪漫、战斗、雨天或安静，由角色从已有歌曲中挑选。
- **歌词互动**：点击播放器当前歌词，或点击陪听窗的 **问这句歌词**，直接和角色讨论歌词。
- **双人模式**：角色可以建议重听或换歌，但不会替用户操作播放器。
- **TTS 语音反应**：复用 SillyTavern 已启用的 TTS 提供商和角色语音映射，通过 `/speak` 朗读陪听回复。

自动互动默认每首最多一次，也可设为两次。开启 **完全安静** 后会关闭切歌回应、中段互动、自动票根和 TTS，手动聊天仍然可用。

> 自定义 API Key、陪听对话、双人歌单与音乐记忆会保存在当前浏览器站点的 `localStorage` 中。自定义服务还需要允许 SillyTavern 所在网页跨域访问；若服务不允许 CORS，请改用 SillyTavern 当前模型模式或调整服务端跨域设置。

### 导入歌单

点击 **导入歌单**，粘贴支持的歌单链接：

- 网易云音乐歌单链接
- QQ 音乐歌单链接

### 世界书作者推荐歌单

仓库提供了可直接导入 SillyTavern 的 [`Selene作者推荐歌单-世界书模板.json`](./Selene作者推荐歌单-世界书模板.json)。导入后可将世界书绑定给角色，也可以作为普通世界书保存；点击播放器中 **导入歌单** 后面的 **读取推荐** 即可读取。

世界书条目可以保持禁用，避免歌单内容进入聊天提示词。播放器会读取 `<selene_playlist>` 专用标签，不会把世界书的普通正文误识别成歌曲。

作者只需按下面的格式填写歌名和歌手，每首歌占两行：

```text
<selene_playlist>
歌单名：角色名的推荐歌单

歌曲：Too Much
歌手：Dove Cameron

歌曲：微醺夜
歌手：Veena
</selene_playlist>
```

也支持一行简写：

```text
<selene_playlist>
Too Much | Dove Cameron
微醺夜 | Veena
</selene_playlist>
```

请保留开头与结尾的 `<selene_playlist>` 标签。读取成功后，可以逐首播放、收藏或加入队列，也可以点击 **全部入队** / **一键播放**。

### 设置里的功能

- **自动读取推荐**：AI 回复中出现歌曲推荐时，自动搜索并播放。
- **系统媒体保活**：未选中任何歌曲时运行静音媒体，并在锁屏、控制中心或状态栏中显示 `SillyTavern` 和内置专辑图；选中歌曲后，播放和暂停状态都由歌曲独占系统媒体卡片，避免静音保活抢走播放按钮。扩展版使用内置 AAC，脚本版使用兼容的 44.1kHz WAV。
- **与其他应用播放**：默认使用“优先播放”，在支持 Audio Session 的浏览器中请求 `playback` 音频会话，并在非手动中断后尝试恢复；切换“允许同时播放”后请求 `ambient` 混音，让支持该接口的系统尝试与其他应用共播。
- **回到保活**：扩展设置栏中的手动切换按钮。点击后暂停当前歌曲并让静音媒体接管；下次从播放器播放歌曲时，静音保活会自动让位。
- **主题**：切换跟随系统、日间或夜间模式。
- **桌面歌词 / 手机版悬浮歌词**：分别控制电脑端和手机端的歌词显示。
- **歌词主色 / 渐变副色**：调整悬浮歌词颜色。
- **独立尺寸调整**：分别修改按钮、文字、封面和歌曲列表的大小。
- **重置歌词位置**：歌词位置跑偏时恢复默认位置。
- **恢复播放器默认尺寸**：播放器窗口大小乱掉时一键恢复。

### Selene 扩展控制栏

在 SillyTavern 的扩展设置页中展开「Selene 音乐播放器」，可以：

- 显示或隐藏播放器窗口。
- 显示或隐藏角色陪听窗口。
- 选择启动 SillyTavern 时是否自动显示播放器。
- 选择是否在扩展菜单显示「音乐播放器」入口。
- 启用或停止系统媒体保活，并查看是否已经真正开始播放。
- 在支持 Media Session 的浏览器中，锁屏或控制中心会显示当前歌曲、歌手、专辑封面、真实时长与进度，并可播放、暂停、切换歌曲或拖动进度。
- 播放器会在真实音频开始播放、封面更新及页面回到前台时重新提交歌名与歌手，减少 Chrome 控制中心只显示应用名称的问题。
- Android Chrome、Android/Windows Edge 与 iOS Safari 均可通过浏览器的 Media Session 接入系统媒体界面；首次播放必须由用户点击歌曲或播放键触发。部分安卓系统还需要允许浏览器通知、后台活动并关闭严格省电限制。
- 设置面板会直接显示当前浏览器是否检测到 `navigator.mediaSession`；这可用于检查雨见等采用不同内核的浏览器版本。
- 分别重置播放器位置与窗口尺寸。

### 系统媒体保活怎么开

可以从「Selene 音乐播放器」扩展控制栏开启，也可以在播放器中打开：

**⚙ → 系统媒体保活 → ▶ 启动保活**

开启后会在尚未选中歌曲时播放本地静音媒体，并以 `SillyTavern` 名称和内置专辑图显示在锁屏、控制中心或状态栏。一旦选中歌曲，静音保活就会让位，即使歌曲处于暂停状态也不会抢走系统媒体卡片。状态栏的播放按钮会恢复当前歌曲。如果浏览器没有自动开始，扩展控制栏会显示原生音频播放条，点击其中的播放键即可。

显示 **系统媒体已播放** 或 **系统媒体已启动** 就代表已经开启。iPhone/iPad 切到后台后，控制中心或锁屏界面可能显示 Chrome/SillyTavern 的媒体控制；不需要时可以点击 **■ 停止保活**。

> 系统媒体保活可以降低浏览器休眠导致暂停播放或掉线的概率，但如果手机系统直接冻结或关闭浏览器，网页无法保证百分之百不断线。

> “优先播放”和“允许同时播放”是两种不同的系统音频策略：前者更积极地争取媒体焦点，后者允许混音。网页扩展不能越过 Android/iOS 强制获得永久最高优先级，实际行为仍取决于浏览器内核、系统省电策略和厂商限制。

## 数据来源与使用说明

- **音乐与歌词数据**：[GD 音乐台](https://music.gdstudio.xyz)
- 播放器恢复 1.1 版 GD 严格匹配与播放流程；播放失败时会自动重试 5 次。
- 手机端不再使用静音占位音源预热主播放器，避免 Safari 已载入音源却被误判为播放超时。
- 本扩展仅作为第三方播放器界面，不在仓库中储存或提供音乐文件。
- 音乐搜索、音频及歌词服务的可用性、内容与地区限制由对应第三方服务决定。
- 本项目仅供个人学习与交流使用，请勿用于商业用途。
- 使用时请遵守当地法律法规、音乐平台条款及数据来源方的使用要求。
- 如相关服务失效、接口调整或歌曲版权受限，部分歌曲可能出现无法搜索、播放或显示歌词的情况。

> 本项目与网易云音乐、QQ 音乐、酷狗音乐及 GD 音乐台均无官方隶属或合作关系。
